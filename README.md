# Airplane

C++ console application for selecting a flight, checking available seats and displaying a simple aircraft status report.

## What It Demonstrates

- classes and methods in C++
- menu-driven console interaction
- simple flight-selection logic
- basic use of `std::map` and `std::string`

## Project Structure

```text
Avion1.sln          # Visual Studio solution
Avion1/
  Avion1.cpp        # application source code
  Avion1.vcxproj    # Visual Studio C++ project
```

## Build And Run

Open `Avion1.sln` in Visual Studio and run the project, or compile `Avion1/Avion1.cpp` with a C++ compiler.
